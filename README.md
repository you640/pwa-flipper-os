# PWA Flipper OS

A Progressive Web App inspired by Flipper Zero, built with React, TypeScript, and Vite.

## Getting Started

### Prerequisites

Make sure you have one of the following installed:

- [Node.js](https://nodejs.org/) (v18 or later) with npm
- or [Bun](https://bun.sh/)

### Clone the repository

```bash
git clone https://github.com/you640/pwa-flipper-os.git
cd pwa-flipper-os
```

### Install dependencies

Using npm:
```bash
npm install
```

Using Bun:
```bash
bun install
```

### Run locally

Using npm:
```bash
npm run dev
```

Using Bun:
```bash
bun dev
```

The app will be available at `http://localhost:8080` (or the port shown in your terminal).

### Build for production

```bash
npm run build
```

### Run tests

```bash
npm test
```
